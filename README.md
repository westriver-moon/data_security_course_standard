# 数据安全系统设计与实践：课程标准工程

本仓库保存教师提供的原始课程工程，源文件位于 `datasec/`，各任务保留课程原始作答区。

## 内容

- `datasec/main.py`：项目入口。
- `datasec/utils.py`：运行组织、数据读写、日志和结果汇总。
- `datasec/01_数据资产盘点与质量治理/`：数据清洗、敏感信息识别和字段分级。
- `datasec/02_数据流转分析与使用决策/`：用途字段与保护规则。
- `datasec/03_数据共享与安全发布/`：假名化、匿名化和统计发布。
- `datasec/04_跨机构联合分析/`：设备匹配、保护求和和联邦训练。
- `datasec/05_数据使用管理与过程追踪/`：结果核验、审计链和操作查询。
- `datasec/数据集/`：课程提供的三张合成数据表。
- `datasec/项目说明.pdf`、各任务的 `任务背景.pdf`：课程要求。
- `datasec/实验报告模板.docx`：任务报告和项目报告模板。

## 运行

使用 Python 3.10 及以上版本：

```bash
cd datasec
python -m pip install -r requirements.txt
python main.py
```

指定任务并运行其必要前序，例如：

```bash
python main.py --task 4
```

业务依赖为任务1 → 任务2 →〔任务3、任务4〕→ 任务5。每次运行结果位于 `datasec/runs/RUN-.../`，从其中的 `项目运行概览.md` 查看结果。
